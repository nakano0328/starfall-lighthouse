# クレジット・ライセンス一覧

本プロジェクトで使用しているライブラリと素材の一覧です。ソースコード自体は [MIT License](../LICENSE) です。

## ルール

- **素材（画像・音・フォント）やライブラリを追加したら、必ず本表に 1 行追加する。** 追加のない PR はレビューで差し戻す
- 「作者」「ライセンス」「URL」は配布元の記載をそのまま写す。CC BY 系は表記義務を満たすため作者名を省略しない
- 「使用箇所」は `public/assets/` 以下のパスか、ゲーム内の用途（例: 村のタイルセット、戦闘 BGM）を書く
- 自作・コード生成の素材（`BootScene` のプレースホルダー等）は記載不要。生成画像は `docs/ART_PROMPTS.md` の採用記録に残す
- エンディングのスタッフロールは本表から生成する（`docs/GAME_DESIGN.md` §11.5）。表の体裁を崩さない
