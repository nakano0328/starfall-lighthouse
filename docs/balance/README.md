# バランス表（`npm run balance` の出力）

`scripts/export-balance.ts` が `src/data/` の敵・エンカウント・装備・スキル・成長曲線を CSV に書き出し、`docs/GAME_DESIGN.md` §6.2 の想定レベル曲線をデータで検算する（PLAN Phase 4 #5–6）。数値を直したら `npm run balance` を実行して CSV を更新し、同じコミットに含める。

| ファイル            | 内容                                                                              |
| ------------------- | --------------------------------------------------------------------------------- |
| `enemies.csv`       | §8.1 / §8.4 の敵：ステータス・属性・弱点・耐性・EXP・G・ドロップ                  |
| `encounters.csv`    | §8.2 のグループ：構成・平均 Lv・1 戦の EXP と G（生存者全員に満額、§5.10）        |
| `equipment.csv`     | §7.2〜7.4 の装備：枠・ティア・装備可能者・価格・補正・属性・耐性                  |
| `skills.csv`        | §4.4 / §8.3 のスキル：種別・対象・属性・MP・倍率・加算・命中・状態異常            |
| `level_curve.csv`   | §6.1 の累計 EXP と、各レベルでの 3 人のステータス（装備なし）・習得スキル         |
| `chapter_curve.csv` | §6.2 の想定ルート（章ごとの戦闘数＋ボス）を実データで積算したときの到達 Lv と判定 |

実行方法：`scripts/run-ts.mjs` が Vite のモジュールランナーで TypeScript を読み込むので、`@core/*` などのパスエイリアスがアプリと同じ解決になる（依存の追加なし）。

## §6.2 の検算（現在のデータ）

| 章                   | 1 戦の EXP（データ／仕様） | 戦闘数 | ボス EXP | 累計 EXP | 到達 Lv | 想定   |
| -------------------- | -------------------------- | ------ | -------- | -------- | ------- | ------ |
| 海岸街道・森（1 章） | 30 ／ 30                   | 12     | 120      | 480      | 5       | 5〜6   |
| 山道・廃坑（2 章）   | 133 ／ 130                 | 14     | 450      | 2,792    | 10      | 10     |
| 磯の道・遺跡（3 章） | 409 ／ 400                 | 14     | 1,200    | 9,718    | 16      | 16     |
| 灯台（終章）         | 609 ／ 800                 | 16     | 3,000    | 22,462   | 22      | 22〜25 |

- 初版のデータでは 2 章以降が §6.2 より低く（Lv9 / 14 / 21）、仕様の「1 戦の平均 EXP」に届いていなかった。§8.1 の通常敵のうち廃坑 4 種を ×1.25、遺跡 3 種を ×1.4 に引き上げて（`en_mine_rat` 36→45、`en_ore_spider` 44→55、`en_minecart_ghost` 52→65、`en_glow_bug` 40→50、`en_tidepool_crab` 120→170、`en_ruin_statue` 140→195、`en_hollow_shell` 130→180）、想定の戦闘数で各章の到達 Lv に合わせた。HP・攻撃などの戦闘数値は変えていない
- 灯台の 1 戦あたり EXP は仕様の 800 に対して 609（`grp_tower_c` に迷い星スライムが混ざるため）。3 章までの貯金で終章の到達 Lv は 22 に届くので据え置き。寄り道込みで Lv25 を狙うなら `en_shadow_hand` / `en_false_light` を 300 前後に上げる

## ボス戦の目安（e2e のシード探索から）

通常攻撃だけ・初期装備で戦った場合の勝敗（`src/core/battle` のエンジンをシード 1〜30 で総当たり）：

| ボス             | 想定 Lv | 通常攻撃のみの結果                                                                                                                     |
| ---------------- | ------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 古木のウロ       | 5       | Lv8 で勝てる（e2e は Lv8・シード 1）                                                                                                   |
| 岩のゴーレム     | 10      | Lv12 で勝てる（e2e は Lv12・シード 1）                                                                                                 |
| 遺跡の番人       | 16      | Lv16〜18 では勝てず、Lv20 で勝てる。土スキル・やまわりの大槌・大潮の防御を前提にした設計どおり                                         |
| ノクス（2 形態） | 22〜25  | Lv30・Tier4 装備でも第 2 形態の「星の消滅」で全滅する。防御（半減）と光属性の充填中断が必須。e2e は 1 HP に落とす probe で流れだけ確認 |

番人とノクスは「通常攻撃で押し切れない」のが意図なので数値は変えていない。実機で遊んで厳しければ `sk_bo_great_tide` / `sk_bo_star_extinction` の倍率か、防御の軽減率（§5.7）で調整する。
