# 『ほしふる灯台』ゲームデザイン仕様書（仕様の正本）

本書は `docs/PLAN.md` の企画を実装可能な粒度まで落とした仕様の正本です。Phase 2〜5 の実装はすべて本書を根拠とし、本書と実装が食い違った場合は本書を直すか実装を直すかを必ず決めて両者を一致させます。
数値はすべて初版バランスで、Phase 7 の調整対象です。ただし **式・ID・データ構造は固定** とし、調整はデータ値の変更のみで行います。

## 2. ID・命名規約

### 2.1 基本ルール

- すべての ID は **snake_case の英小文字＋数字** とし、接頭辞で種別を表す。
- ID は一度公開（タグ付きリリース）したら変更しない。表示名（日本語）は自由に変えてよい。
- データファイル名・画像キー・シーン名などコード側の識別子はすべて英語。表示文字列のみ日本語。

### 3.2 遺跡の潮の干満ギミック

- 状態はフラグ `ruins.tide`（`'high'` 初期値 / `'low'`）。マップ内の「潮の石碑」（`trigger` オブジェクト、`event_id: ev_ruins_tide_toggle`）を調べると切り替わる。石碑は上層 2 箇所・下層 1 箇所。
- 切り替え時は画面を青白くフェード（600ms）し、`se_tide` を再生。切り替え中は入力を受け付けない。
- Tiled 上では `collision_high` と `collision_low` の 2 つの当たり判定レイヤーと、`deco_water_high`／`deco_water_low` の 2 つの装飾レイヤーを持つ。実装は `ruins.tide` に応じて使用レイヤーを選ぶ（§9.4）。
- 満潮時：中央の広間が水没し北側通路のみ通れる。干潮時：広間が通れる代わりに東側の水路が干上がって下層の宝箱部屋へ降りられるが、北側通路は閉じる（潮位でせり上がる柵）。
- 敵シンボルは水没タイル上に生成しない（`enemy` オブジェクトに `tide: 'low'|'high'|'any'` プロパティ）。
- `ruins.tide_learned`（学者から `it_tide_rune` を受け取る）が偽のうちは石碑を調べても「文字が読めない」と表示されるだけで切り替わらない。

### 4.2 ステータス定義

| ステータス | キー  | 意味                                                   |
| ---------- | ----- | ------------------------------------------------------ |
| HP         | `hp`  | 0 で戦闘不能                                           |
| MP         | `mp`  | スキル消費                                             |
| 攻撃       | `atk` | 物理・魔法ともダメージの基礎（魔法専用ステは置かない） |
| 防御       | `def` | 被ダメージ軽減                                         |
| 素早さ     | `spd` | 行動順・命中・回避・逃走                               |
| 運         | `luk` | クリティカル率・ドロップ率補正                         |

成長は線形：`stat(Lv) = floor(base + growth × (Lv − 1))`。

## 5. 戦闘仕様

### 5.1 コマンド一覧

| コマンド | 内容                                                             |
| -------- | ---------------------------------------------------------------- |
| たたかう | 通常攻撃（物理、倍率 ×1.0、命中 95）。対象は敵単体               |
| スキル   | 習得スキルから選択。MP 不足はグレー表示                          |
| アイテム | 戦闘で使えるアイテム（`usableInBattle: true`）のみ表示           |
| 防御     | そのターンの被ダメージ ×0.5。素早さに関係なく最初に成立          |
| 逃げる   | パーティ全体で逃走を試みる（§5.9）。ボス戦では選択不可（グレー） |

- コマンド入力はラウンド開始時にパーティ全員分を先に入力（キャラ順：ルカ→ミオ→ゴロー、X で一人前へ戻る）。
- 入力完了後に敵の行動を AI で決定し、全員の行動順を確定して解決する。
- 対象が行動時点で戦闘不能／消滅していた場合、同種の別の対象へ自動変更（敵→生存敵のランダム、味方回復→HP 割合最低の生存者）。

### 5.2 行動順

```
initiative = SPD_total × rand(0.85, 1.15)
```

- 毎ラウンド全員を `initiative` 降順でソート。同値はランダム。
- `priority: true` の行動（防御、`sk_smoke_bomb`、`sk_provoke`、アイテム使用）は initiative に +1000 して常に先頭グループになる（グループ内は initiative 順）。
- 麻痺中は行動をスキップ（コマンドは入力させない。入力時点で麻痺なら「しびれて動けない」）。
- ノクス第 1 形態 HP50% 以下の「2 回行動」は、同ラウンド内に行動を 2 回登録する（2 回目は initiative − 500）。

### 5.3 ダメージ式

```
ATK_a = (基礎攻撃 + 装備攻撃) × (攻撃アップ中 ? 1.3 : 1.0)
DEF_t = (基礎防御 + 装備防御) × (防御ダウン中 ? 0.7 : 1.0)

physical: base = ATK_a × mult + add − DEF_t / 2
magic:    base = ATK_a × mult + add − DEF_t / 4
base = max(base, 1)

dmg = floor(base × elem × crit × guard × rand(0.9, 1.1))
dmg = max(dmg, 1)
```

| 係数    | 値                                                                                           |
| ------- | -------------------------------------------------------------------------------------------- |
| `elem`  | 弱点 1.5 / 通常 1.0 / 耐性 0.5 / 無効 0（§5.5）                                              |
| `crit`  | クリティカル時 1.5、通常 1.0。物理のみ発生                                                   |
| `guard` | 対象が防御中 0.5、通常 1.0                                                                   |
| 乱数    | 一様乱数。テスト用に `rng` を注入可能にする（`core/battle` は `Math.random` を直接呼ばない） |

クリティカル率（%）：`clamp(5 + floor(LUK_a / 5) + skill.critBonus, 0, 50)`。敵の LUK は表に持たず 0 固定（基本 5%）。

**アイテムダメージ**：`dmg = floor(power × elem × guard × rand(0.9, 1.1))`（防御を無視、クリティカルなし）。

**回復量**：`heal = floor((add + Lv_a × lvMult) × rand(0.95, 1.05))`。アイテムは固定値（`it_potion_l` などは全快）。戦闘不能の味方には回復スキルは無効（対象に選べない）。

**ゴーレムの硬化**（§8.4）など「物理無効」は `elem` ではなく `EnemyState.physicalImmune` として別フラグで扱い、ダメージ 0 かつ「カキン！」表示。

### 5.4 命中・回避

```
hit% = clamp(accuracy + (SPD_a − SPD_t) / 2, 60, 100)
暗闇中の攻撃側: hit% = hit% × 0.6
対象が麻痺中: hit% = 100
```

- `accuracy`：通常攻撃 95、物理スキルは各定義（既定 95）、魔法・回復・バフ・アイテムは必中（判定なし）。
- 状態異常の付与判定は命中後に別途行う：`付与% = skill.statusChance × (1 − target.statusResist[status])`。ボスは麻痺耐性 1.0（無効）、他の状態異常は耐性 0.5。

### 5.5 属性と弱点マトリクス

属性は `light` / `fire` / `water` / `earth` の 4 種＋ `none`。敵は「自身の属性」とは別に `weak[]` / `resist[]` を明示する（§8）。マトリクスは敵定義を作る際の既定ルール：

| 敵の属性     | 弱点（×1.5） | 耐性（×0.5） |
| ------------ | ------------ | ------------ |
| 炎           | 水           | 炎           |
| 水           | 土           | 水           |
| 土           | 炎           | 土           |
| 光           | —            | 光           |
| 無（影タグ） | 光           | —            |
| 無           | —            | —            |

- 「影」は属性ではなくタグ（`tags: ['shadow']`）。影タグの敵は光が弱点。
- 味方側の属性耐性は装備で付く（例：`eq_acc_sea_ring` 水 ×0.5）。味方に弱点はない。
- 弱点ヒット時は「こうかはばつぐん！」の文言と `se_weak` を再生し、属性アイコン（UI-03）を点滅させる（色弱配慮でアイコン併用）。

### 5.6 状態異常

| 状態       | キー       | 継続     | 毎ターン効果（行動者のターン終了時） | 行動・能力への影響              | 治療アイテム                 | 治療スキル |
| ---------- | ---------- | -------- | ------------------------------------ | ------------------------------- | ---------------------------- | ---------- |
| 毒         | `poison`   | 5 ターン | 最大 HP の 8%（最低 3）のダメージ    | なし                            | `it_antidote`, `it_panacea`  | `sk_cure`  |
| 麻痺       | `paralyze` | 2 ターン | なし                                 | 行動不可、被命中 100%、防御不可 | `it_numb_herb`, `it_panacea` | `sk_cure`  |
| 暗闇       | `blind`    | 4 ターン | なし                                 | 物理命中 ×0.6                   | `it_eye_drop`, `it_panacea`  | `sk_cure`  |
| 防御ダウン | `def_down` | 3 ターン | なし                                 | DEF ×0.7                        | `it_panacea`                 | `sk_cure`  |
| 攻撃アップ | `atk_up`   | 3 ターン | なし                                 | ATK ×1.3                        | （解除不要）                 | —          |

- 同じ状態を再付与した場合は継続ターンをリセット（重ね掛けなし）。
- 継続ターンは「付与された者のターン終了時」に 1 減り、0 で解除（メッセージ表示）。
- **戦闘終了時にすべての状態異常を解除**する（フィールドに持ち越さない）。毒はフィールドでダメージを与えない。
- 戦闘不能（`ko`）は状態異常とは別扱い：HP0 で付与、`it_star_feather` か宿屋で回復。**戦闘終了時に戦闘不能のまま残った味方は HP1 で復帰**する（詰み防止）。
- 挑発（`taunt`）：3 ターンの間、敵の単体攻撃（対象ルールが `random`/`lowest_hp` のもの）の対象をゴローへ強制。アイコンなし、HP バー横に「盾」記号を表示。

### 5.7 防御コマンド

- 選択ターンのみ有効。被ダメージ ×0.5（`guard`）。状態異常付与は防げない。
- 麻痺中は選択不可。
- 実装上は `BattlerState.guarding = true` をラウンド開始時に立て、ラウンド終了時に下ろす。

### 5.8 敵 AI 行動テーブル形式

敵ごとに `ai: AiRule[]` を持つ。各ルールは次の形：

| 列         | 意味                                                                                                                                                                                                                                                                                                                                     |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `priority` | 大きいほど優先。条件を満たすルールのうち最大 `priority` の集合から `weight` で重み抽選                                                                                                                                                                                                                                                   |
| `cond`     | `always` / `hp_below:0.5`（自 HP 割合）/ `turn_every:3`（ターン番号が 3 の倍数）/ `turn_eq:1` / `ally_count_below:2` / `party_has_status:blind` / `self_has_status:atk_up` / `not_self_status:atk_up` / `charge:n`（n 回目の充填）/ `all:[…]`（列挙した条件をすべて満たす。例：番人の `hp_below:0.5` かつ `not_self_status:water_veil`） |
| `action`   | `attack`（通常攻撃）か スキル ID。擬似行動として `guard`（防御）、`charge`（充填を 1 段進める。行動を消費）、`double_act`（以降 2 回行動。行動を消費せず同ラウンドに再抽選）も可                                                                                                                                                         |
| `message`  | 行動前に表示する台詞・演出文（任意）                                                                                                                                                                                                                                                                                                     |
| `target`   | `random` / `lowest_hp` / `highest_atk` / `all` / `self` / `ally_random`                                                                                                                                                                                                                                                                  |
| `weight`   | 重み（整数）                                                                                                                                                                                                                                                                                                                             |
| `once`     | 戦闘中 1 回のみ（任意）                                                                                                                                                                                                                                                                                                                  |

通常敵の既定パターン：`priority 0: always → attack(random) weight 60 / 固有スキル weight 40`。各敵の表（§8）には固有部分のみ記す。

充填の規約：`charge` 行動、または `charging` 状態を自分に付与するスキル（番人の `sk_bo_tide_omen`）で充填カウントが 1 増える。`charge:n` 条件で選ばれた行動は実行時にカウントが変わっていれば無効（中断後は「ひるんで動けない」）。充填中に充填以外の行動を取るとカウントは 0 に戻る（= 大技の発動で消費）。

### 5.9 逃げる

```
逃走成功% = clamp(50 + (平均SPD_party − 最大SPD_enemy) × 2 + 15 × 失敗回数, 20, 95)
```

- 成功：戦闘終了、EXP・ゴールドなし。フィールド復帰後 3 秒間プレイヤー無敵（点滅）、接触した敵シンボルは 3 秒硬直。
- 失敗：パーティ全員がそのラウンドを消費（防御なし）。失敗回数は戦闘中累積。
- `EncounterGroup.canEscape === false`（ボス）では選択不可。

### 5.10 報酬

- EXP：倒した敵の `exp` 合計を **生存メンバー全員にそれぞれ全額**、戦闘不能メンバーには半額（floor）。分配しない。
- ゴールド：`gold` 合計。
- ドロップ：敵 1 体につき `drop` を 1 回判定。`判定% = drop.chance × (1 + 最大LUK_party / 200)`（LUK66 で約 1.33 倍）。ドロップは 1 種 1 個。
- リザルト画面：獲得 EXP／ゴールド／アイテム → レベルアップ演出（上昇値表示、習得スキル）。Z で早送り。

### 5.11 勝敗・ゲームオーバー

- 敵全滅で勝利。パーティ全員戦闘不能で敗北。
- 敗北 → `GameOverScene`（KV-03 背景、`bgm_gameover`）→ 選択肢「最後のセーブから再開」「タイトルへ」。セーブが 1 つもない場合は「タイトルへ」のみ。
- ボス戦はリトライ優遇として、敗北時に「ボス前のセーブポイントから再開（HP/MP 全快、ボス前の状態）」を 3 つ目の選択肢として表示する（実装は直前の自動バックアップ `starfall.save.auto` を使う。スロット扱いにはしない）。

### 5.12 シンボルエンカウント

| 項目         | 仕様                                                                                                                                                 |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| 配置         | Tiled `enemy` オブジェクト（§9.3）。1 シンボル = 1 グループ抽選                                                                                      |
| 待機挙動     | 出現地点から半径 4 タイル内をランダム歩行（0.8〜1.2 秒に 1 タイル）                                                                                  |
| 追跡         | プレイヤーが 5 タイル以内かつ視線が通る（当たり判定レイヤーで遮られない）とき追跡。追跡速度 1 タイル / 0.3 秒、距離 8 で諦める                       |
| 開戦         | プレイヤーとシンボルが同一タイルまたは隣接で接触。接触方向が背後（プレイヤーの向きの逆）なら「先制攻撃」（敵の最初のラウンド行動なし）、正面なら通常 |
| 勝利後       | シンボル消滅。`respawn_sec`（既定 60）経過後に **マップへ再入場した時** に再生成。同一マップ滞在中は復活しない                                       |

| 無敵時間     | マップ遷移直後 1 秒、逃走後 3 秒、イベント中は常に無敵                                                                                               |
| 生成制限     | 1 マップに同時表示 8 体まで                                                                                                                          |

### 5.13 バトル速度設定

設定「バトル速度」が「速い」の場合、ダメージ数字・メッセージ表示の待機時間を 0.5 倍にする。

## 9. フィールド仕様

### 9.1 移動

| 項目       | 仕様                                                                                            |
| ---------- | ----------------------------------------------------------------------------------------------- |
| グリッド   | 32px、4 方向。斜め入力は「最後に押された方向」を優先                                            |
| 速度       | 歩き 150ms / タイル。ダッシュ（Shift / ゲームパッド B 長押し / タッチ A+B）100ms / タイル       |
| 移動不可時 | 向きだけ変える。壁押し中は足音を鳴らさない                                                      |
| 入力先行   | 移動完了 40ms 前から次の入力を受け付け、連続移動を滑らかにする                                  |
| カメラ     | プレイヤー追従、マップ境界でクランプ。マップが画面より小さい軸は中央寄せ                        |
| アニメ     | 歩行 4 方向 × 3 フレーム（CC0 スプライト規格に合わせ 32×32 または 32×48）。停止時は中央フレーム |
| 座標       | セーブの `location.x/y` はタイル座標。描画位置は `(x × 32 + 16, y × 32 + 16)` を基準            |

### 9.2 インタラクション

Z（決定）で向いているタイルのオブジェクトに作用する。優先順：NPC ＞ 宝箱 ＞ 看板 ＞ セーブポイント ＞ 扉（鍵付きワープ）。足元が `trigger` の場合は踏んだ瞬間に発火。

| 対象           | 挙動                                                                                                                                       |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 話す（NPC）    | NPC がプレイヤーの方を向き、`dialog` の会話を開始。終了後は元の向きに戻る                                                                  |
| 調べる（看板） | `text_id` の会話ノードを話者なしで表示                                                                                                     |
| 宝箱           | 未開封なら開封アニメ → `se_chest` → 「○○を手に入れた！」→ `chest.<flag>` を true。開封済みは「からっぽだ」                                 |
| 扉（鍵付き）   | `warp` に `required_item` があれば所持確認。所持なら「かぎを使った」→ 以後 `door.<map>_<n>` フラグで開放。なければ `locked_text_id` を表示 |
| セーブポイント | 「星の祠」。調べるとセーブ画面（§12）。保存時に `se_save` と光の演出。HP/MP 回復はしない                                                   |
| 出入口（warp） | 踏むと `fade out 250ms → マップ切替 → fade in 250ms`。遷移後 1 秒無敵（フェードは HUD より下、§10.2 fade 参照）                            |
| ショップ       | `npc` の `shop` プロパティがあれば会話後に「買う／売る／やめる」                                                                           |
| 宿屋           | `npc` の `inn_price` があれば「○G で泊まりますか？」→ 全快 → 画面暗転 → セーブ画面                                                         |

### 9.3 Tiled 規約

> **作成方法（ADR-0002）**: マップは Tiled ではなく `src/data/maps/<map_id>.ts` の ASCII 形式で記述し、`compileMap()` が本節の規約どおりの Tiled 互換 JSON を生成する。本節は **生成される JSON の仕様** である。Tiled でエクスポートした JSON も同じ規約に従うため、将来 `public/assets/maps/*.json` を読む経路を足せば同じ `parseMapObjects` / `CollisionGrid` で扱える（現時点のローダーは ASCII ソースのみ）。

**全般**

- 直交（orthogonal）、タイル 32×32、描画順 right-down。マップ最大 64×64。
- タイルセットは **マップに埋め込み（Embed in map）**。外部 .tsx 参照を使わない。
- 書式：JSON。Tiled で描く場合は「Export As → JSON map files (.json)」でエクスポートし、ファイル名 `<map_id>.json` を `public/assets/maps/` に置く（現在は未使用。置く場合も手で編集しない）。
- マップのカスタムプロパティ：`bgm`（string, BGM キー）、`display_name`（string）、`entrance_x` / `entrance_y`（int、`it_return_feather` の戻り先）、`battle_bg`（string）。

**タイルレイヤー（名前固定、上から描画順）**

| レイヤー名  | 種別   | 用途                                                                    |
| ----------- | ------ | ----------------------------------------------------------------------- |
| `ground`    | tile   | 地面。必ず全面を埋める                                                  |
| `deco`      | tile   | 地面上の装飾（プレイヤーの下に描く）                                    |
| `above`     | tile   | プレイヤーの上に描く（木の上部、屋根）                                  |
| `collision` | tile   | 通行不可。`ts_collision` の赤タイル（gid 任意、非空＝不可）。表示しない |
| `events`    | object | オブジェクトレイヤー（下記）                                            |

遺跡上層のみ `collision_high` / `collision_low` / `deco_water_high` / `deco_water_low` を追加し、`collision` と `deco` は共通部分に使う。

**オブジェクト（`events` レイヤー）**：Tiled の「クラス（Type）」にオブジェクト種別、カスタムプロパティに引数。位置はタイルにスナップ（32 の倍数）。

| type         | 必須プロパティ                                                                                 | 任意プロパティ                                                                                                                                                                                                                             | 備考                                                                                                                        |
| ------------ | ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| `npc`        | `id`(string `npc_*`), `dialog`(string `dlg_*`), `facing`(up/down/left/right), `sprite`(string) | `move`(static/random, 既定 static), `shop`(string `shop_*`), `inn_price`(int), `condition`(string), `hidden_if`(string), `markers`(JSON 文字列 `[{"if":condition,"text":"！"}]`。最初に成立した要素の `text` を頭上に表示、空文字で非表示) | `dialog` は会話ツリーの入口ノード。段階分岐はノード側の `branches` で行う。`move: random` は出現地点から半径 2 タイルを歩く |

| `chest`      | `item_id`(string `it_*`/`eq_*`/`gold`), `qty`(int), `flag`(string `chest.*`)                   | `tide`(high/low/any)                                                                                                                                                                                                                       | `gold` のとき `qty` がゴールド額                                                                                            |
| `sign`       | `text_id`(string `dlg_*`)                                                                      | —                                                                                                                                                                                                                                          |                                                                                                                             |

`condition` の文法：`flag.key`（真）、`!flag.key`（偽）、`flag.key>=3` / `==` / `<`（数値）、`flag.key=='low'`（文字列）。`item.<item_id>>=3` は所持数を参照する（保存はされない）。1 条件のみ（AND が必要なら事前に合成フラグを立てる）。

**タイルセット命名**：`public/assets/images/tiles/ts_<area>.png`。`ts_village`, `ts_interior`, `ts_forest`, `ts_mine`, `ts_ruins`, `ts_lighthouse`, `ts_collision`。CC0 素材を取り込む際も同名に揃え、出典は `docs/CREDITS.md` に記載。

### 9.4 マップメタデータ

`MapMeta`（§16）は各マップの `MapSource.meta` として `src/data/maps/<map_id>.ts` に持ち、`src/data/maps/index.ts` の `MAP_SOURCES` に登録する。BGM・表示名・出現グループ・章の制約はここでコード側に型チェックさせる。生成 JSON（Tiled 側）の `bgm` 等と重複する場合は **`MapMeta` を正** とする。

## 10. 会話・イベントスクリプト

### 10.1 会話データ（JSON）

配置：`src/data/dialogs/<area>.json`（`minato.json`, `forest.json`, `hagane.json`, `mine.json`, `ruins.json`, `lighthouse.json`, `common.json`）。ビルド時に静的 import し、起動時にスキーマ検証（Vitest でも全ファイルを検証）。

```jsonc
{
  "dlg_grandpa_01": {
    "speaker": "じいちゃん", // 省略時は名前枠なし（看板・ナレーション）
    "portrait": "portrait_grandpa_neutral", // 省略可
    "pages": ["ルカ、灯台の油が切れかけとる。", "これを届けてきてくれんか。"],
    "effects": [{ "cmd": "give_item", "item": "it_lamp_oil", "qty": 1 }],
    "next": "dlg_grandpa_02",
  },
  "dlg_grandpa_02": {
    "speaker": "じいちゃん",
    "portrait": "portrait_grandpa_smile",
    "pages": ["気をつけてな。"],
    "choices": [
      { "text": "はい", "next": "dlg_grandpa_03" },
      {
        "text": "……ちょっと怖い",
        "next": "dlg_grandpa_03b",
        "effects": [{ "cmd": "set_flag", "key": "minato.luka_scared", "value": true }],
      },
    ],
  },
  "dlg_grandpa_entry": {
    "pages": [],
    "branches": [
      { "if": "fragments.count>=3", "next": "dlg_grandpa_final" },
      { "if": "main.core_shattered", "next": "dlg_grandpa_after_shatter" },
      { "if": "minato.intro_done", "next": "dlg_grandpa_02" },
      { "next": "dlg_grandpa_01" },
    ],
  },
}
```

| フィールド | 型              | 意味                                                                                                          |
| ---------- | --------------- | ------------------------------------------------------------------------------------------------------------- |
| `speaker`  | string?         | 名前枠に表示                                                                                                  |
| `portrait` | string?         | 顔アイコンのアセットキー                                                                                      |
| `pages`    | string[]        | 1 ページ = 1 ウィンドウ（最大 3 行 × 22 文字目安）。`\n` で改行。空配列なら表示せず分岐のみ                   |
| `choices`  | Choice[]?       | 最終ページ表示後に選択肢。`text`, `next`, `effects`                                                           |
| `branches` | Branch[]?       | 上から順に `if`（§9.3 の condition 文法）を評価し最初に合致した `next` へ。`if` なしは既定                    |
| `effects`  | EventCommand[]? | 最終ページ表示後に実行（`set_flag`, `give_item`, `give_gold`, `take_item`, `play_se`, `heal_party` のみ許可） |
| `next`     | string?         | 続きのノード。なければ会話終了                                                                                |

テキスト中の制御記法：`{luka}` などのパーティ名置換（将来の名前変更に備える）、`{gold}` 所持金、`{item:it_herb}` アイテム名。

### 10.2 イベントスクリプト（コマンド列）

配置：`src/data/events/<area>.json`。`ev_*` ごとに `EventCommand[]`。実行中はプレイヤー入力を奪い、敵シンボルを停止する。

| cmd                        | 引数                                                                  | 意味                                                                                                                                         |
| -------------------------- | --------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `move`                     | `actor`(`player`/`npc_*`), `path`(方向配列), `wait`(bool 既定 true)   | 1 タイルずつ移動。`wait:false` で次コマンドと並行                                                                                            |
| `face`                     | `actor`, `dir`                                                        | 向きを変える                                                                                                                                 |
| `wait`                     | `ms`                                                                  | 待機                                                                                                                                         |
| `say`                      | `dialog`(`dlg_*`)                                                     | 会話ノードを表示（分岐・選択肢込み）。終了まで待つ                                                                                           |
| `choice`                   | `text`[], `set`(string フラグキー)                                    | 選択肢を出し、選んだインデックスを `set` のフラグへ数値で保存                                                                                |
| `give_item`                | `item`, `qty`                                                         | 入手メッセージ付き                                                                                                                           |
| `give_gold`                | `amount`                                                              | 所持金に加算（入手メッセージ付き）。会話の `effects` でも使用可                                                                              |
| `take_item`                | `item`, `qty`                                                         | 所持数不足なら 0 まで                                                                                                                        |
| `set_flag`                 | `key`, `value`(bool/number/string) または `increment`(number)         | フラグ操作                                                                                                                                   |
| `battle`                   | `group`(`grp_*`), `win_event`(`ev_*`?), `lose`(`gameover`/`continue`) | 戦闘開始。勝利後 `win_event` を実行。`lose:continue` はイベント戦用（v1 未使用）                                                             |

| `fade`                     | `dir`(`in`/`out`), `ms`, `color`(既定 black)                          | 画面フェード。HUD（会話ウィンドウ・章タイトル）より下の全画面オーバーレイなので、暗転中も `say` の文章は読める（§10.3 の ev_opening が前提） |

| `play_bgm`                 | `key`(`bgm_*` または `none`), `fade_ms`                               | BGM 切替                                                                                                                                     |
| `play_se`                  | `key`(`se_*`)                                                         | 効果音                                                                                                                                       |
| `heal_party`               | —                                                                     | HP/MP 全快・戦闘不能回復・状態異常解除                                                                                                       |
| `add_member`               | `id`(`ch_*`)                                                          | パーティ加入（EXP 同期、初期装備付与）                                                                                                       |
| `show_chapter`             | `title`                                                               | 章タイトルを 2.5 秒表示                                                                                                                      |
| `spawn_npc` / `remove_npc` | `id`                                                                  | イベント専用 NPC の出し入れ                                                                                                                  |
| `flash`                    | `ms`, `color`                                                         | 画面フラッシュ                                                                                                                               |
| `end_game`                 | —                                                                     | エンディングシーンへ                                                                                                                         |

`if` 分岐はスクリプト内に持たず、`trigger` の `condition` と会話ノードの `branches` に寄せる（スクリプトを直線に保つ）。

## 12. セーブ仕様

### 12.1 スキーマ v1（Phase 2 前半。現行は §12.2 の v2）

```ts
export const SAVE_SCHEMA_VERSION = 1;
export const SAVE_SLOT_COUNT = 3;
export const SAVE_KEY_PREFIX = 'starfall.save.'; // キー: starfall.save.0 / .1 / .2

interface SaveData {
  schemaVersion: number; // 1
  savedAt: number; // Unix ms
  playTimeSec: number; // 累計プレイ秒
  location: {
    map: string; // マップ ID
    x: number; // タイル座標
    y: number;
    facing: 'up' | 'down' | 'left' | 'right';
  };
  flags: FlagMap; // Record<string, boolean | number | string>
}
```

- `deserialize` は壊れた JSON・形違い・**より新しい schemaVersion** を `null` にする。古いバージョンは `migrate()` で 1 段ずつ上げる。
- `createNewSave` は `location.map = 'map_minato_luka_house'`（x7, y7, up）を返す（`tests/unit/save.test.ts` で検証）。ニューゲーム直後に同じタイルの `trigger` が `ev_opening` を発火する（§10.3）。
- スロット以外に `starfall.save.auto`（ボス前自動バックアップ、§5.11）と `starfall.settings`（設定）を持つ。これらは `SAVE_SLOT_COUNT` の範囲外で `slotKey()` を通さない。

### 12.2 現行スキーマ v2（`src/core/save.ts` と一致）

  | 'enemy_all'
  | 'enemy_random' // hits 回ランダム

  | 'ally_all'
  | 'self'

  mp: number;
  atk: number;
  def: number;
  spd: number;

// ---- キャラクター -----------------------------------------------------

  growth: Stats; // 1 レベルごとの増分（小数可）。stat(Lv) = floor(base + growth * (Lv - 1))

  turns: number;

}

  description: string;
  mpCost: number;
  kind: SkillKind;

  mult: number; // ATK 倍率（heal では未使用）
  add: number; // 固定加算（heal では基礎回復量）
  lvMult?: number; // heal のみ: add + Lv * lvMult

  accuracy?: number; // physical のみ（既定 95）

  description: string;
  category: ItemCategory;
  price: number; // 0 = 非売品（売却不可）

  usableInField: boolean;

    | { type: 'heal_hp'; amount: number | 'full' }
    | { type: 'heal_mp'; amount: number | 'full' }

    | { type: 'damage'; power: number; element: Element }

  name: string;

  slot: EquipSlot;

  bonus: Partial<Stats>;

## 付録 A. 数値バランスの検算メモ
